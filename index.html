What a scan can read

Unique device IDs, manufacturer and model information, DMX address, channel footprint, and supported personalities. The exact controls still require a matching fixture profile.

What you need

RDM-capable lights, an RDM-capable USB interface or network node, and a local bridge. Any splitters in the path must pass RDM. Conventional DMX lights need a manual patch.
